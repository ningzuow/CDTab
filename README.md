# CDTab
The codes in this warehouse are used for learning purposes.
We hope to apply the deep learning approach for the enhancement of tabular data imbalance, and use the contrastive learning method to improve the enhancement effect.

## Related Work
Our model code has learned from TabDiff and MoCo v3. If you want to understand the more fundamental principles and details, you can visit the following link:
